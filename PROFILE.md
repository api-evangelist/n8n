# n8n

n8n is a fair-code workflow automation and iPaaS platform with AI-agent tooling. It exposes an instance-scoped REST API (public OpenAPI 3.0 contract), MCP server/client capabilities via built-in nodes, and an llms.txt documentation index.

## APIs

- **n8n Public API** — Instance-scoped REST API (path /api/v1) for managing workflows, executions, credentials, users, tags, variables, source control, security audit, and data tables. API-key auth via X-N8N-API-KEY header. Available on paid plans. (`/api/v1`)

> REST API is instance-scoped (call your own n8n Cloud subdomain or self-hosted host at /api/v1); OpenAPI 3.0.0 contract is public in the n8n-io/n8n-docs repo, but live API usage requires a paid plan (not available during free trial). MCP surfaces are per-instance/self-hosted only (MCP Server Trigger node exposes per-workflow URLs on your own instance; MCP Client Tool node consumes external MCP servers) — there is no single central hosted n8n MCP endpoint, so no MCPServer property is cataloged. llms-full.txt is also served at https://docs.n8n.io/llms-full.txt and every doc page is retrievable as Markdown by appending .md. No official GraphQL, AsyncAPI, or Postman contract and no formal published Agent Skills package were found. Possible duplicate n8n entry may already exist in the catalog.
